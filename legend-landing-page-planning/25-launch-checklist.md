# 25 — Launch Checklist

## Client approvals
- [ ] Final logo
- [ ] Final hero image
- [ ] Homepage people list
- [ ] Image rights
- [ ] Final copy
- [ ] Final contact details
- [ ] Story Google Form
- [ ] Partnership Google Form
- [ ] Social links
- [ ] Public PDF approval

## Repository
- [ ] Production branch clean
- [ ] Environment variables set
- [ ] No test URLs
- [ ] No placeholder lorem ipsum
- [ ] No unused large media

## Vercel
- [ ] Project connected
- [ ] Production deployment
- [ ] Custom domain
- [ ] HTTPS
- [ ] www/non-www redirect decision
- [ ] Analytics if required

## Search
- [ ] Google Search Console
- [ ] sitemap submitted
- [ ] robots accessible
- [ ] title/description checked in production

## Social preview
Test sharing in:
- [ ] WhatsApp
- [ ] Instagram DM / browser preview where possible
- [ ] LinkedIn
- [ ] X

## Final device review
Have someone who did not build the page open it on a phone and answer:
1. What is this publication?
2. Who has it featured?
3. How do I read an issue?
4. How do I pitch a story?
5. How does a brand contact them?

If those answers are not obvious, the page is not finished.

## Post-launch
First 7 days:
- check form links;
- check 404s;
- check analytics;
- check image load errors;
- fix mobile clipping immediately.
