# 20 — SEO Plan

## Objective
The site should rank cleanly for the publication's own name and provide strong preview cards when shared.

## Homepage metadata

### Title
**LEGEND Magazine | Extraordinary Stories of Leadership, Business & Culture**

### Description
**Discover LEGEND, a Mumbai-born editorial magazine profiling leaders, builders, creators and institutions shaping business, culture and modern India.**

## Technical requirements
- canonical URL;
- metadataBase;
- Open Graph;
- Twitter card;
- favicon;
- sitemap;
- robots.txt;
- semantic headings;
- descriptive alt text;
- optimized images;
- readable anchor text.

## Next.js metadata
Use `export const metadata`.

## Open Graph image
Create:
```text
/public/images/brand/legend-og.jpg
```

Recommended content:
- LEGEND masthead;
- one strong approved portrait;
- “Excellence · Culture · Vision”;
- clean issue/editorial styling.

## Structured data
For phase one:
- Organization / Magazine-style publishing organization;
- WebSite.

Do not overcomplicate schema with dozens of Person entities if the landing page does not contain detailed profile pages.

## Content SEO
Visible homepage text should naturally include:
- LEGEND Magazine;
- Mumbai;
- leadership;
- business;
- culture;
- developers;
- editorial;
without keyword stuffing.

## Brand search
Ensure:
- exact publication name is in H1/intro or strong visible area;
- social links are consistent;
- domain title is consistent;
- favicon and OG image are branded.

## PDFs
If PDFs are public and indexable:
- use clean file names;
- link them with descriptive labels.

Example:
`legend-july-2026.pdf`
not:
`final-02-compressed(3).pdf`
