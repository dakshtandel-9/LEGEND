# 07 — Grid and Spacing

## Desktop
- max visual container: `1440px`;
- core content width: `1280px`;
- editorial reading width: `720–820px`;
- side padding: `48–64px`;
- 12-column grid;
- gutter: `24px`.

## Tablet
- 8-column grid;
- side padding: `32px`;
- section spacing: `88–104px`.

## Mobile
- 4-column grid;
- side padding: `20–24px`;
- gutter: `16px`;
- section spacing: `72–88px`.

## Section spacing
Premium editorial layouts need more vertical space than a typical marketing site.

Desktop:
- regular section: `112–144px` vertical;
- compact transition: `72–88px`;
- hero: viewport-aware, around `min-height: 78vh`.

Mobile:
- regular: `72–96px`;
- compact: `48–64px`.

## Story grids
Do not use one repeated three-column grid for the entire page.

Create hierarchy:
- one lead story at 7–8 columns;
- one supporting story at 4–5 columns;
- later rows may use 3 cards;
- Developers' Diary can use a 50/50 split.

## Image bleed
Allow selected images to:
- touch container edges;
- break one grid column;
- extend behind labels.

Do this selectively.
