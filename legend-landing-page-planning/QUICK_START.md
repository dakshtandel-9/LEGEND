# Quick Start

1. Put this planning folder in the repository.
2. Add official logo and approved images under `/public/images`.
3. Rename/export the supplied PDFs into `/public/issues`.
4. Create the two Google Forms.
5. Set:
   - `NEXT_PUBLIC_STORY_FORM_URL`
   - `NEXT_PUBLIC_PARTNERSHIP_FORM_URL`
6. Give `26-master-build-prompt.md` to your coding agent.
7. Build and deploy to Vercel.

**Do not add a CRM, database, CMS or custom form backend.**
