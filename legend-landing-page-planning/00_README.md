# LEGEND Landing Page Planning Pack

This folder is the complete pre-development specification for the LEGEND landing page.

It is deliberately designed for a **simple Vercel deployment** with no backend, no CRM and no CMS.

## Recommended build stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- `next/image`
- `next/font`
- Framer Motion only where motion genuinely improves the editorial experience
- Google Forms for enquiries
- Vercel for deployment

## Build sequence
Do not begin with animation or detailed styling.

1. Collect official assets.
2. Confirm copy and people allowed on the homepage.
3. Build wireframe.
4. Establish design tokens.
5. Build all static sections.
6. Add responsive behavior.
7. Connect Google Form CTAs/embeds.
8. Add motion.
9. Add metadata and SEO.
10. Test and deploy.

## Important
The palette in this pack is a proposed digital interpretation of the supplied magazine issues. If the client has official brand guidelines, those values override the proposed values here.
