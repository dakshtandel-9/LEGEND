# 23 — Analytics Events

Analytics is optional but recommended.

Possible tools:
- Vercel Analytics;
- GA4.

No CRM is involved.

## Core events

```text
hero_latest_issue_click
hero_pitch_story_click

featured_person_click

issue_may_open
issue_july_open

story_card_click

developers_diary_click

pitch_story_click
partnership_click

instagram_click
email_click
```

## Google Form limitation
If the form opens on `docs.google.com`, the website can reliably track the outbound CTA click.
Form completion itself is not automatically visible to your site unless separately configured inside Google's ecosystem.

## Metrics to watch
- top CTA clicks;
- issue PDF opens;
- scroll depth;
- mobile vs desktop;
- outbound form clicks.

## Do not over-track
The purpose is to understand whether the landing page is:
- creating readership;
- generating editorial interest;
- generating partnership interest.
