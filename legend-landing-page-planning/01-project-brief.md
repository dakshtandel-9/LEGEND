# 01 — Project Brief

## Project
LEGEND Magazine — Digital Landing Page

## Client need
Create a premium online presence for LEGEND that can be confidently shared with readers, business leaders, public figures, celebrities, developers, brands and potential editorial subjects.

This is not intended to become a full news website in phase one. It is a focused, high-quality landing page that communicates the brand and directs users to editions, stories and enquiry forms.

## Product definition
A responsive one-page editorial website containing:
- masthead/header;
- premium hero;
- featured personalities;
- latest editions;
- featured stories;
- Developers' Diary spotlight;
- editorial philosophy;
- editorial verticals;
- story-pitch call to action;
- advertising/partnership call to action;
- contact/footer.

## Primary audiences

### 1. Readers
Need to quickly understand what LEGEND covers and access current editions.

### 2. Potential profile subjects
Founders, developers, public figures, leaders and creators should understand the type of stories LEGEND publishes and be able to pitch a story.

### 3. Brands / advertisers
Need an obvious path to discuss advertising, campaigns or partnerships.

### 4. PR / communications teams
Need proof of the publication's positioning, previous subjects and contact route.

## Primary conversion goals
1. Open latest issue.
2. Explore a featured story/profile.
3. Submit “Pitch Your Story” Google Form.
4. Submit partnership/advertising Google Form.

## Secondary goals
- brand recall;
- increased legitimacy when the link is shared;
- improved search visibility;
- stronger visual consistency across future issues.

## Scope

### Included
- one responsive landing page;
- local static images;
- local issue PDF links;
- two Google Forms;
- basic analytics;
- SEO metadata;
- issue/story/person content stored in local project files.

### Explicitly excluded
- CRM;
- database;
- CMS;
- account system;
- login;
- admin panel;
- article editor;
- payment system;
- subscriptions with payment;
- custom mail backend;
- custom form backend.

## Success criteria
The page succeeds if a first-time visitor can answer these questions within roughly 20 seconds:
- What is LEGEND?
- What kind of people/stories does it feature?
- Is it credible and premium?
- What is the latest edition?
- How can I pitch a story?
- How can my brand work with LEGEND?
